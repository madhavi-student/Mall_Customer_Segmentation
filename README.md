# Mall Customer Segmentation

## Project Description
This project uses Machine Learning to group mall customers
based on their annual income and spending score.

## Objective
To identify customer groups using the K-Means Clustering algorithm.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Visual Studio Code

## Algorithm
K-Means Clustering

## Dataset
Sample mall customer data containing:
- Customer ID
- Gender
- Age
- Annual Income
- Spending Score

## Implementation Steps
1. Create the customer dataset.
2. Select annual income and spending score.
3. Standardize the features.
4. Apply K-Means clustering.
5. Visualize the customer groups.
6. Save the clustering results as a CSV file.

## Result
The customers are divided into three clusters.
The cluster sizes depend on the input dataset.
